# Manga Store Template 📚🛒

A modern, responsive e-commerce storefront template designed for a digital manga retailer. This project is built using native **JavaScript (ES6+)** and **Tailwind CSS**, demonstrating core front-end state management, shopping cart arithmetic, and dynamic user interfaces without external framework dependencies.

## 🚀 Live Links
- **Code Repository:** [GitHub Link](https://github.com)

## ✨ Core Features
- **Dynamic Counters:** Real-time updating navigation badges for both the Shopping Cart and Favorites/Wishlist.
- **Dedicated Product Views:** Custom dedicated dashboard layouts to display items currently held in the cart or marked as favorites.
- **Cart Calculations:** Robust mathematical logic to handle item quantity modifications, computing individual item subtotals and the grand order total automatically.
- **Tailwind Grid Layout:** High-density, mobile-responsive media layout specifically structured to display manga cover artwork beautifully across all device viewports.

## 🛠️ Tech Stack
- **Front-End Styling:** Tailwind CSS
- **Application Logic:** JavaScript 
- **Version Control:** Git & GitHub
